# LINE OA 配信結果集計ツール

LINE公式アカウント（@246vizck）の配信結果データを自動収集するPythonスクリプトです。

## 概要

Seleniumを使用してLINE Official Account Managerにログインし、配信インサイトデータを自動的にスクレイピングしてCSVファイルに保存します。
ログイン前後は自動で動作するが、ログイン時にスマホ認証やログインボタンクリックのみ本人の補助が必要。その後は勝手に動き、同ディレに「line_insight_data.csv」が出力される

## 機能

- LINE Official Account Managerへの自動ログイン
- 複数ページにわたる配信結果データの自動収集
- 日時データの整形
- CSV形式でのデータ出力

## 必要な環境

- Python 3.x
- Google Chrome
- ChromeDriver

## 依存パッケージ

```bash
pip install selenium pandas
```

## ファイル構成

- `a.py` - メインスクリプト（配信結果の収集）
- `年月日文字列作成.py` - 日時文字列の分割テストスクリプト
- `line_insight_data.csv` - 収集されたデータの出力ファイル
- `chat.txt` - 作業ログ

## 使い方

1. 依存パッケージのインストール
```bash
pip install selenium pandas
```

2. ChromeDriverのインストール
   - お使いのChromeのバージョンに合ったChromeDriverをダウンロード

3. スクリプトの実行
```bash
python a.py
```

## 設定

`a.py`の以下の設定を必要に応じて変更してください：

- `start_page`: 集計開始ページ（デフォルト: 1）
- `end_page`: 集計終了ページ（デフォルト: 11）

## ⚠️ セキュリティに関する注意

**重要**: 現在、ログイン情報（メールアドレス・パスワード）がスクリプト内にハードコードされています。
本番環境で使用する際は、以下の対策を推奨します：

- 環境変数を使用する
- 設定ファイルを別途作成し、.gitignoreに追加する
- キーチェーンやシークレット管理ツールを使用する

## 出力データ

CSVファイルには以下の情報が含まれます：
- 配信日時
- 配信内容
- 配信結果（開封率、クリック数など）
